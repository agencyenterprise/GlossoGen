# Research programs

This directory contains the scientific record of GlossoGen research programs.
Each program owns its studies and experiment records:

```text
research program -> study -> experiment record -> run
```

| Program | Status | Current direction |
|---|---|---|
| [Covenant Game](covenant-game/README.md) | active | isolate the pledge and personal-cost mechanisms |

Repository-root `experiments/` contains operational campaign assets used to
launch simulations. It is not the scientific record. Raw run outputs live in
`runs/`. The documents under `docs/research/` connect questions and decisions
to exact configs, commands, runs, hashes, analysis, and results.
