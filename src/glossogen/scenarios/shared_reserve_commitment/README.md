# Shared reserve commitment

This scenario is a repeated two-provider common-good task. In each active
round, each provider receives 21 units and chooses either to contribute 7 to a
shared Continuity Reserve or retain all 21. The public ledger reveals both
actions only after both have decided. A fixed, hidden schedule of equal client
claims tests whether accumulated contributions keep the recurring service alive.
An uncovered claim ends future payments for both providers.

The four intended conditions are no group, visible group identity, public
pledge, and a public pledge with a real one-time 2.1-unit entry cost. Group
identity, pledge and entry cost are the only intended treatment differences.
The common reserve, claim schedule, shared ledger, actions, payment, agents,
model, seed and hidden horizon remain matched.

This is a multi-agent extension of the human 7→21 pledge design, not a direct
replication. It models a real shared consequence before testing institutional
mechanisms. It has no audit, fine, bond forfeiture, expulsion, or repair
mechanism; those belong to later studies after the clean pledge ladder is
calibrated.
