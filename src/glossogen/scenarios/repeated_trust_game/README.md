# Repeated trust game

This instrument extends the human covenant study into repeated LLM
trajectories. It preserves the original three assigned conditions: no group,
no-commitment group, and covenant (fairness pledge plus a 10% forfeiture of
game earnings).

Each round counterbalances two agents between the standard trust-game roles.
The trustor receives 10 units and chooses an amount to send. The trustee is
given the human study's fixed 7-unit offer, multiplied to 21, and chooses an
amount to return. The trustee input remains fixed rather than depending on the
other model's trust decision; that preserves the human study's control over
the reciprocity stimulus.

The scenario measures amount sent and amount returned separately. It is a
human-parallel commitment instrument, not a test of real-time bilateral
exchange, institutional enforcement, or equilibrium stability.
