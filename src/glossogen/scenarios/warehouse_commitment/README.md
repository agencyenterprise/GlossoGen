# warehouse_commitment

`warehouse_commitment` is a deliberately reduced two-provider instrument for
the human-parallel commitment question. It is not a replacement for the prior
`bonded_team_production` institutional-bundle scenario.

Each round, both providers decide privately whether to inspect their own
assigned inventory zone or certify without inspection. Inspection receives a
fixed base payment; shortcutting receives the same base payment plus a fixed
private bonus. The gross payoff schedule is held constant across conditions;
the covenant's forfeiture then scales both rewards. The action is recorded by
the world, and the prior aggregate action summary is public at the following
round.

The four conditions are:

1. `no_group` — no shared professional identity.
2. `group` — public group identity without a commitment.
3. `pledge` — group identity plus the explicit fairness-and-commitment pledge.
4. `covenant` — the pledge plus an automatic, non-refundable 10% forfeiture of
   each realized reward.

The 10% forfeiture mirrors the total cost in the human study while making the
state mechanically visible in a repeated-agent world. It is a membership cost,
not a sanction for detected shortcutting. Consequently, this scenario tests
promise adherence under a fixed immediate temptation; it does not establish
long-run institutional enforcement or equilibrium on its own.

## Primary outcomes

- individual inspection rate;
- joint inspection rate;
- first shortcut and persistence after a first shortcut;
- pledge affirmation or decline;
- gross earnings, forfeiture paid, and net earnings.

Each complete run, rather than each round, is an independent trajectory. See
the planned experiment record before launching any model runs.
