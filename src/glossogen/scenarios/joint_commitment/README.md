# Joint commitment

This scenario studies whether public group identity, an explicit pledge, and
a one-time costly pledge change adherence to a shared client-facing
commitment.

Every decision round, two providers each receive a fixed 21-unit payment
containing a 7-unit client reserve. Each chooses to remit the reserve or retain
it. Their choices are private until both are recorded, then appear directly in
a shared client ledger. The client is protected only when both providers remit.

The baseline conditions are no group, group identity only, group pledge, and
costly pledge. Group conditions use a public registry. In the pledge
conditions, both providers' affirmative or declining decisions are shown to
both agents before the first client decision. In the costly-pledge condition,
affirming also deducts one irreversible 2.1-unit entry cost (10% of 21);
declining leaves the provider able to work as a publicly listed non-member.
There are no audits, fines, forfeitures, or status revocations in this baseline.

It is a repeated, two-agent extension of the fixed 7→21 human decision: the
allocation is held constant, while the same providers face a jointly necessary
client outcome over time. It is not a direct human-study replication, a test of
deception, or a full equilibrium and replacement model.
