3A route is one member reaching one teammate. A post on the team's link reaches 

4every teammate, and a direct message reaches the teammate it was sent to. Each 

5round's value counts the distinct routes the team used while it was charged; with 

6four members there are twelve. A team that broadcasts from every member uses all
