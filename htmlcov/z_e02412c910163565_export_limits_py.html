1"""Ceilings on how much one export may cover, and the error raised past them. 

2 

3Three different things are bounded here, so there are three numbers. 

4 

5The **run count** bounds how long a synchronous request runs. Cohorts here reach 

6several thousand runs, and the largest labelled one is around 3,600, so a ceiling 

7below that refuses the work people actually do. Measured: 1,200 runs export in about 

8twelve seconds and 3,580 in about thirteen, because the cost is dominated by the 

9directory scan and not by per-run work. This sits where the request still returns 

10inside a proxy timeout, not where the data stops being interesting. 

11 

12The **raw byte** ceiling is estimated up front by sizing the run folders, and it 

13counts them uncompressed. The zip a client receives is smaller: measured across three 

14scenarios here, 5.7x to 7.0x smaller. So this ceiling is conservative, and 4 GiB 

15counted is around 600 MiB delivered. Sizing first is what makes the refusal cheap, 

16since nothing has to be compressed to find out. 

17 

18The **CSV byte** ceiling bounds the same delivery for the tables, and it counts what 

19the client receives: compressed inside a zip, raw for a bare CSV. Counting the rows' 

20own bytes would hold the two shapes to ceilings differing by the compression ratio, 

21and CSV deflates by two orders of magnitude. 

22 

23It is counted during the write, not estimated beforehand. Row count is a poor 

24stand-in, because the long tables repeat the run columns onto every row by default 

25and repetition is exactly what deflate removes: turning it off cut one cohort's 

26uncompressed bytes sixfold and its delivered bytes by about a fifth. Counting is 

27exact, and the archive is fully built before a byte of it is sent, so stopping partway 

28costs only the temporary file. 

29 

30A single CSV is the one shape where counted equals delivered, so this number is the 

31size it really permits there. One cohort's round-level table alone reaches 273 MiB, 

32which is a large object for a browser tab to hold, and that is what the setting buys. 

33 

34The CSV ceiling applies to the HTTP path only, since `glossogen export` writes to a 

35directory and nothing holds a table in memory. The raw ceiling does apply to the CLI: 

36`--raw` goes through the same writer, and the command turns a breach into a clean 

37exit. 

38""" 

39 

40MAX_EXPORT_RUN_COUNT: int = 5000 

41 

42MAX_RAW_EXPORT_BYTES: int = 4 * 1024 * 1024 * 1024 

43 

44MAX_CSV_EXPORT_BYTES: int = 512 * 1024 * 1024 

45 

46 

47class ExportTooLargeError(Exception): 

48 """A selection exceeds one of the export ceilings. 

49 

50 Carries the message a caller is shown, so the limit is stated once here and not 

51 reworded at each surface. 

52 """ 

53 

54 

55def _gibibytes(count: int) -> str: 

56 """Render a byte count in GiB, to one decimal.""" 

57 return f"{count / (1024 * 1024 * 1024):.1f} GiB" 

58 

59 

60def _mebibytes(count: int) -> str: 

61 """Render a byte count in MiB, to the nearest whole one.""" 

62 return f"{count / (1024 * 1024):.0f} MiB" 

63 

64 

65def check_run_count(run_count: int) -> None: 

66 """Raise :class:`ExportTooLargeError` if ``run_count`` is over the ceiling.""" 

67 if run_count > MAX_EXPORT_RUN_COUNT: 

68 raise ExportTooLargeError( 

69 f"This selection is {run_count} runs. The limit is {MAX_EXPORT_RUN_COUNT}. " 

70 "Narrow the filters, select fewer runs, or use the glossogen export command." 

71 ) 

72 

73 

74def check_raw_bytes(total_bytes: int) -> None: 

75 """Raise :class:`ExportTooLargeError` if ``total_bytes`` is over the ceiling.""" 

76 if total_bytes > MAX_RAW_EXPORT_BYTES: 

77 raise ExportTooLargeError( 

78 f"These run folders total {_gibibytes(total_bytes)}. The limit is " 

79 f"{_gibibytes(MAX_RAW_EXPORT_BYTES)}. Narrow the filters or select fewer runs." 

80 ) 

81 

82 

83def check_csv_bytes(total_bytes: int) -> None: 

84 """Raise :class:`ExportTooLargeError` if the tables written are over the ceiling.""" 

85 if total_bytes > MAX_CSV_EXPORT_BYTES: 

86 raise ExportTooLargeError( 

87 f"These tables exceed {_mebibytes(MAX_CSV_EXPORT_BYTES)} to download. Select " 

88 "fewer runs, drop the long tables, or use the glossogen export command, which " 

89 "writes to a directory and has no such limit." 

90 )
