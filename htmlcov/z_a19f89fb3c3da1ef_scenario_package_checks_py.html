1"""Checks on the project around a scenario loaded from a path. 

2 

3:mod:`glossogen.scenario_authoring.scenario_conformance` checks a built scenario, 

4which says nothing about how the project around it is packaged. A project whose 

5``pyproject.toml`` builds a wheel has to ship the prompts and presets as package 

6data: one that omits them installs a wheel that renders nothing, while the source 

7tree the author tests against works fine. 

8 

9A check that cannot be evaluated returns a note rather than a verdict, because a 

10false failure teaches a reader to skip the output.

177def _files_needing_packaging(module_dir: Path) -> list[str]: 

178 """Return every prompt and preset under the module, relative and posix-formed."""
