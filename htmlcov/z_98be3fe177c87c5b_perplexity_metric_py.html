1"""Perplexity metric: mean per-token surprisal of primary-channel messages. 

2 

3Uses ``minicons.scorer.IncrementalLMScorer`` with ``gpt2`` to compute the mean 

4per-token surprisal (in nats) of every message sent on the scenario's primary 

5channel. Produces an overall scalar score plus a per-round breakdown. 

6Deterministic: it does not consult the LLM provider. 

7 

8Scores the **pristine** text the sender composed, not what the channel 

9delivered: when a scenario transforms outgoing messages (e.g. veyru channel 

10noise replaces dropped characters with ``_``), each primary-channel 

11``MessageSent`` is resolved back to its pre-transform text via the 

12``message_id`` link. Runs with no transform (or predating that link) score the 

13transmitted text unchanged. 

14"""

92def _load_gpt2_scorer() -> MessageScorer: 

93 """Load gpt2 and return a scorer of mean per-token surprisal in nats per text. 

94 

95 Callers must confirm the perplexity backend is installed before invoking this. 

96 Minicons returns NaN for inputs that tokenize to a single token (no left context). 

97 """ 

98 device = resolve_torch_device() 

99 logger.info("perplexity: loading %s on %s", _MODEL_NAME, device) 

100 incremental_lm_scorer = load_incremental_lm_scorer() 

101 lm_scorer: Any = incremental_lm_scorer(_MODEL_NAME, device) 

102 

103 # minicons.IncrementalLMScorer is untyped; ``reduction`` is called with a 

104 # torch.Tensor whose ``.mean(0).item()`` is a float. 

105 def _negative_mean(tensor: Any) -> float: 

106 return -tensor.mean(0).item() 

107 

108 def score_texts(texts: list[str]) -> list[float]: 

109 raw_scores: list[float] = lm_scorer.sequence_score(texts, reduction=_negative_mean) 

110 return [float(score) for score in raw_scores]
