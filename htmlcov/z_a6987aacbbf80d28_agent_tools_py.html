1"""The tools one agent is offered, built as pydantic-ai function tools. 

2 

3Every tool runs in the runner's process, in the calling agent's own task. The 

4agent id is bound when the tool is built: an executor receives it as its 

5``agent_id`` argument and the model never supplies it, so the remaining 

6parameters are the schema the model sees. A tool refuses a call by raising 

7``ValueError``, which reaches the model as the tool's error in the executor's 

8words; any other exception is logged here and reaches the model as 

9``Error executing tool <name>``.

11``list_tool_definitions`` describes the same tools without binding an agent,
