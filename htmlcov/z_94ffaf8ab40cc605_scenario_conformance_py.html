1"""Check a scenario against the contract, without launching it. 

2 

3`SimulationScenario` is an ABC, so Python already enforces that the abstract 

4methods exist. What it cannot enforce is that they agree with each other: an 

5agent may list a channel nobody created, a preset may have drifted from the 

6knobs model it is validated against, `get_agent_roles` may name a different set 

7of agents than `get_agents` builds. Each of those surfaces as a confusing 

8failure minutes into a paid run, or as a metric that silently scores nothing. 

9 

10These live here rather than in the test suite because a scenario can ship from 

11any distribution, and the tests do not. `glossogen check-scenario <name>` runs 

12them against whatever the loader resolves, which is the same set the CLI can 

13launch; the repository's own conformance suite runs them over the built-ins. 

14 

15Every check is a function taking a built scenario and returning the reason it 

16failed, or None. That shape is what lets one run report every problem rather 

17than the first. 

18"""
