1"""How a scenario exposes its own tools to agents. 

2 

3A scenario returns one ``ScenarioMcpTool`` per tool from ``get_mcp_tools``, and 

4the runtime registers each with FastMCP alongside the base communication tools. 

5 

6An executor that needs to know who called it takes a ``ctx: ToolContext`` first 

7argument and passes it to ``resolve_agent_id``, which reads the id off the MCP 

8connection URL. FastMCP fills the context in and keeps it out of the schema the 

9model sees, so identity is a property of the connection rather than something 

10the model supplies per call. 

11"""
