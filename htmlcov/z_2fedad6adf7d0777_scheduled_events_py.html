1"""Declarative round-boundary interventions. 

2 

3Defines the data model for the scheduled actions a simulation can perform 

4at the start of a given round: swapping one agent for a fresh instance 

5(with a configurable per-channel history visibility), disabling 

6postmortem, and injecting a case. The schedule is carried inside scenario knobs as a 

7``scheduled_events`` list and dispatched by the runtime's 

8``RoundBoundaryScheduler`` when the game clock advances.

76class InjectCase(BaseModel): 

77 """Override the round-N case with a scenario-supplied payload. 

78 

79 The runtime hands ``payload`` opaquely to the scenario's 

80 ``inject_case_payload`` hook at the start of ``at_round``; the scenario
