1"""What a client asks an export for. 

2 

3Which runs is a tagged union of two shapes, not one shape holding both a filter set 

4and an id list. "Both were given" is then unrepresentable, so there is no precedence 

5rule to document or to get wrong. It also matches how the choice gets made: either 

6these specific runs, or everything matching what I am looking at. 

7 

8Columns are named explicitly, with no "all" flag. A request that lists its columns is 

9reproducible: the same body exports the same table later, and the export can record 

10verbatim what it was asked for. "All columns" is the caller echoing back the keys the 

11preview offered. 

12"""

37class FilterRunSelection(BaseModel): 

38 """Runs named by the same filters the runs list uses. 

39 

40 Mirrors the runs list without paging: ``scenario`` is OR-matched, ``labels`` 

41 are AND-matched, ``run_id_contains`` is a case-insensitive substring of 

42 ``scenario/run_dir_name``, ``status`` restricts to one run status, and 

43 ``contains_agent_id`` keeps runs that registered that agent. Each ``knob`` 

44 entry is one ``<knob><operator><value>`` condition on the run's recorded 

45 ``scenario_config``, and every one of them has to hold. 

46 

47 Every filter empty means every run the caller can see. 

48 

49 The set matches the list's own filters, so any selection the list can show is one 

50 the export can reproduce. 

51 """ 

52 

53 # Extra keys are refused so the two shapes really are exclusive: without 

54 # this, a filter selection carrying run_ids is accepted and the ids ignored. 

55 model_config = ConfigDict(extra="forbid") 

56 

57 kind: Literal["filters"] 

58 scenario: list[str] 

59 labels: list[str] 

60 run_id_contains: str | None 

61 status: RunStatus | None 

62 contains_agent_id: str | None 

63 # The one field here with a default, because this model is also persisted: a 

64 # dashboard saved before knob filtering existed has no such key, and reading 

65 # it back has to keep working. Absent and empty mean the same thing, so the 

66 # default cannot be mistaken for a filter someone meant to set. 

67 knob: list[str] = Field(default_factory=list) 

68 

69 @field_validator("knob") 

70 @classmethod 

71 def _knob_conditions_parse(cls, raw_filters: list[str]) -> list[str]: 

72 """Refuse a condition that carries no operator. 

73 

74 Validating on the model rather than at each call site is what makes the 

75 three export endpoints answer 422 instead of 500, and makes the CLI fail 

76 with the same message rather than dropping the condition and exporting a 

77 wider set than was asked for. 

78 """ 

79 try: 

80 parse_knob_filters(raw_filters=raw_filters) 

81 except KnobFilterParseError as exc: 

82 raise ValueError(str(exc)) from exc 

83 return raw_filters 

84 

85 def parsed_knob_conditions(self) -> list[KnobFilter]: 

86 """The parsed form of ``knob``. Validation already proved every entry parses.""" 

87 return parse_knob_filters(raw_filters=self.knob)

107class ExportPreviewRequest(BaseModel): 

108 """Body for the export preview. 

109 

110 ``include_raw_size_estimate`` opts into walking the selected run directories 

111 for their on-disk size. It is the only part of the preview that costs one 

112 filesystem stat per file, so the CSV side leaves it off. 

113 

114 ``include_logs`` is what the estimate is taken with. The logs are roughly half 

115 the size of a run folder again, so an estimate that ignored it would sit under 

116 the checkbox that changes it and never move. 

117 """

131class CsvExportRequest(BaseModel): 

132 """Body for the CSV export. 

133 

134 ``frames`` picks which tables to emit. ``columns`` names the run-context 

135 columns to carry, and ``metrics`` the evaluator metrics, which are one column 

136 each on every table that carries scores. ``repeat_run_columns`` copies the run 

137 context onto every row of the per-round, per-agent and per-message tables so 

138 they read without joining back to the run-level table. 

139 ``include_metric_summaries`` adds each metric's unit and one-line rollup at run 

140 level and its per-observation note on the other tables, which roughly triples 

141 the run-level table's width. 

142 

143 ``metrics`` reaches neither the message nor the round-context table, whose 

144 cells are what an agent said and what it was told rather than measurements. 

145 """ 

146 

147 selection: RunSelection 

148 frames: list[ExportFrame] 

149 columns: list[str] 

150 metrics: list[str] 

151 repeat_run_columns: bool 

152 include_metric_summaries: bool
